# Math and Geometry Projects

This folder contains beginner-level Python projects focused on mathematical calculations and geometric shapes.

## Projects

### 01. Triangle Area and Perimeter Calculator

A beginner-level Python program that calculates the area and perimeter of a triangle using the user's input.

**Features:**
- Takes three side lengths as input.
- Takes the triangle's height as input.
- Calculates the area of the triangle.
- Calculates the perimeter of the triangle.
- Displays the results in the terminal.

**Mathematical Formulas:**

Area = (Base × Height) / 2

Perimeter = Side A + Side B + Side C

**Python Concepts Used:**
- `print()`
- `input()`
- Variables
- `float()`
- Arithmetic Operators
- Basic Mathematical Operations

**File:** `01-Triangle-Calculator.py`

### 05. Sphere Volume and Surface Area Calculator

A beginner-level Python program that calculates the volume and surface area of a sphere using the radius provided by the user.

**Features:**
- Takes the radius of the sphere as input.
- Calculates the volume of the sphere.
- Calculates the surface area of the sphere.
- Displays both results in the terminal.

**Mathematical Formulas:**

Volume = (4 × π × Radius³) / 3

Surface Area = 4 × π × Radius²

**Python Concepts Used:**
- `print()`
- `input()`
- Variables
- `float()`
- Exponentiation Operator (`**`)
- Arithmetic Operators
- Basic Mathematical Operations

**File:** `05-Sphere-Calculator.py`
